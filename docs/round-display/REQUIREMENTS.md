## 目标与已确认需求

硬件为微雪 ESP32-S3-Touch-AMOLED-1.75C，圆形 1.75 英寸 AMOLED，466×466；CO5300 显示控制器，CST9217 触控控制器。2026-10-21 esptool 实测：ESP32-S3 revision v0.2，双核最高 240 MHz，8 MB PSRAM，32 MB Flash。历史串口 /dev/cu.usbmodem1101，接手时重新发现，不硬编码。

官方资料：https://www.waveshare.com/esp32-s3-touch-amoled-1.75c.htm
官方示例：https://github.com/waveshareteam/ESP32-S3-Touch-AMOLED-1.75C

供应商文档存在 Flash 数值差异，当前板以实测 32 MB 为依据。芯片同为 S3 不代表板级引脚相同，显示、触控、背光/亮度、电源、按键和 USB 配置必须核对 1.75C 原理图和官方示例。

## 界面

四个主页面依次为 Overview、Usage、Sessions、Context。保留黑底、荧光绿、白色主文字，异常使用橙红色。所有信息必须位于圆形可视区域，不能只把 480×480 缩成 466×466。

- 左右滑动切换四个主页面。
- 仅在 Usage 内，上下滑切换供应商，使用整页吸附过渡。
- 下方横排圆点表示主页面；Usage 右侧竖排圆点表示供应商。
- 只有一个供应商时隐藏竖排提示，不产生空页面。
- 识别主要滑动方向并锁定一次手势，避免斜滑同时切换两个维度。
- 进入和离开 Usage 时保留已选择的供应商，列表刷新按稳定 ID 保留选择；供应商消失则选有效回退项。
- Usage 展示供应商名称、额度窗口、已用百分比、剩余百分比、重置倒计时和本地重置日期时间。
- 默认优先展示 Codex；其他供应商由 Magpie 实际返回决定，不能写死 Claude 模拟数据进生产。
- 同一供应商多个额度窗口全部保留；优先呈现最受限的有限窗口，同时明确窗口名称。布局可加紧凑次要窗口行，不能混合不同窗口的百分比和重置时间。
- 额度接近耗尽时使用警示颜色，阈值作为可调整实现参数，不是固定业务规则。

## 数据与边界

百分比是供应商账户额度，不能冒称 GPT-5 单模型额度。每个供应商显示自己的窗口及重置时间。缺字段、未知、无限额度必须分别处理，不能默认 100% 剩余或 0% 已用。无返回的供应商不凭空创建。

倒计时根据绝对重置时间和可靠时间锚点每秒本地更新，无须每秒请求 Mac。长时间显示可简写天/小时，临近重置显示分钟/秒。到零显示等待更新并触发/等待正常刷新，不假定额度恢复。断连或超过 60 秒无新快照时标记过期；休眠唤醒后重新校准。

继续保留上游加密 BLE、配对、自动重连、15 秒刷新、60 秒无操作熄屏、触摸唤醒以及安全限定的快捷操作；按键映射根据目标板重新确认。

## 验收

- 目标板构建成功，屏幕和触摸坐标准确，四页无圆边裁切。
- Usage 水平与垂直手势互不误触，只有一个供应商时正确退化。
- 使用 Codex+Claude 合成 fixture 验证两个供应商各自百分比和倒计时；Claude 必须标注为测试数据。
- 测试缺失额度、无限额度、多窗口、过期时间、重连、数据乱序及供应商增删。
- 每条 BLE 消息符合协商后的实际大小上限，多消息快照不能混入上一批数据。
- 不在设备、截图或日志中暴露 API Key、邮箱、请求正文。
- 固件实际烧录及后台服务安装在完成构建、审查、备份恢复方案后由用户明确确认。
